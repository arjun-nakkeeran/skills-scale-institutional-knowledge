# OctoAcme Project Management Docs

This README collects links to all project management process documents maintained in the docs/ folder and provides a short summary of OctoAcme's approach to project management.

## Project management processes (brief summary)

OctoAcme uses a lightweight, outcomes-focused project management approach combining iterative planning and clear role responsibilities:

- Initiation: Define objectives, scope, success criteria, and stakeholders. Use a short initiation checklist to confirm alignment before planning.
- Planning: Create a prioritized roadmap, decompose work into milestones and tasks, and assign owners. Timeboxed planning sessions set clear deliverables and acceptance criteria.
- Execution & tracking: Track progress with weekly syncs and lightweight status updates. Use issue boards to visualize work and surface blockers early.
- Risks & communication: Maintain a risk register with owners and escalation paths. Proactive stakeholder communication uses templated updates and clear RACI assignments.
- Release & deployment: Follow a release checklist that covers testing, rollback plans, and release communication.
- Retrospective & continuous improvement: Hold retros after major milestones to capture actionable improvements and update process docs accordingly.
